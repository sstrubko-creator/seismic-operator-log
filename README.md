# Журнал оператора сейсморазведки

Адаптивное одностраничное веб-приложение для заполнения полевого журнала и экспорта в Excel (`.xlsx`).

## Запуск
1. Откройте `index.html` в современном браузере (Chrome, Edge, Safari, Firefox).
2. При первом запуске для экспорта XLSX требуется интернет: библиотека SheetJS загружается с CDN.
3. Данные автоматически сохраняются в `localStorage` браузера.
4. Кнопка **Экспорт XLSX** создает книгу с листами: «Паспорт проекта», «Оборудование», «Параметры съемки», «Исполнители», «Операторский журнал».

## Что реализовано
- адаптивный интерфейс для ПК и телефона;
- пошаговая форма;
- динамические таблицы источников, приемников, исполнителей и операторских записей;
- автосохранение в браузере;
- демонстрационные данные;
- экспорт в Excel;
- базовые поля для QC, синхронизации и хронологии простоев.

## Развертывание
Это статическое приложение. Его можно разместить на GitHub Pages, GitLab Pages, Netlify, Vercel или на внутреннем веб-сервере без backend.
