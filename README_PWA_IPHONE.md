# Установка на iPhone как PWA

Это версия того же журнала, адаптированная для установки на экран «Домой» iPhone.

## Важно
PWA нельзя корректно установить непосредственно из ZIP или через `file://`. Нужна HTTPS-ссылка на папку с приложением.

## Самый простой запуск
1. Распакуйте архив.
2. Разместите содержимое папки `seismic_operator_log_app` на любом статическом HTTPS-хостинге (GitHub Pages, Netlify, Cloudflare Pages или корпоративный веб-сервер).
3. Откройте полученную HTTPS-ссылку именно в Safari на iPhone.
4. Нажмите кнопку «Поделиться».
5. Выберите «На экран Домой».
6. Нажмите «Добавить».
7. Запускайте приложение с появившейся иконки «Сейсможурнал».

После первого онлайн-запуска основные файлы приложения кэшируются для офлайн-работы. Данные формы по-прежнему сохраняются в браузере устройства, а Excel выгружается средствами Safari/iOS в «Файлы» или через меню «Поделиться».

## Что добавлено в PWA-версию
- manifest.webmanifest;
- иконки 180/192/512 px;
- standalone-режим;
- service worker;
- кэширование интерфейса и библиотеки XLSX для работы без сети после первоначальной загрузки;
- iOS-метатеги для запуска с экрана «Домой».
